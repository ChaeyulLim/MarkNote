## 원칙 (결정됨)
- **AI 는 조언만 하지 않고 직접 고친다** — 바로 적용 + `되돌리기 | 확정` (노트·프레젠테이션 모두)
- Claude 는 사용자의 **구독 로그인**으로 서버의 Claude Code CLI 를 실행. 앱은 Claude 로그인·토큰을 다루지 않는다
- **DB 를 쓰지 않는다** — 노트는 `instance/notes/<프로젝트>/<노트>.md`, 나머지도 파일 ([storage.md](/p/5)). 대화 기록도 파일(JSONL)
- 민감한 내용은 **비공개 표시**로 AI 에게 보내지 않는다
- 로그인은 **IP 가 아니라 기기(브라우저 쿠키) 단위**로 유지 — 같은 와이파이·회사망의 다른 사람이 들어오지 않게

## 된 것
| 영역 | 내용 |
|---|---|
| 노트 | 블록 편집기, 페이지 트리, 보관함·휴지통, 가져오기/내보내기(.md/.zip), 단축키 |
| **파일 저장** | DB 없이 `instance/notes/회사/회의록.md` (하위 노트는 `회사/회의록/3월.md`). 앱 밖에서 파일을 고치거나 넣어도 반영. 페이지 위·폴더 목록·사이드바에 **파일 위치** 표시, 마우스를 올리면 실제 위치, 복사 버튼·우클릭 "파일 위치 복사". 예전 DB 는 `flask --app run import-db instance/marknote.db` 로 한 번 옮김 |
| AI 도우미 | 오른쪽 서랍(F2), 지금 화면·선택한 글자 전달, 노트 읽기·검색, 설정 화면 |
| AI 표시 | 모델·노력 수준 선택, 사용량 고리 — **세션 한도 %·초기화 시각**, 95% 이상 경고, 100% 면 보내기 전에 막음 |
| 대화 유지 | 페이지를 옮겨도 대화·진행 중 답변 유지, 파일 기록 |
| `/resume` | 대화 목록·검색·이어 가기, 이름 바꾸기(`/rename`, 목록의 연필), 삭제(trash), `/new`, Claude 쪽 기록이 지워져도 최근 대화를 다시 보내 이어 감 |
| 프로젝트 폴더 | 최상위 페이지 = 프로젝트(📁, `새 프로젝트`), 그 안에 노트(＋). **같은 폴더 안 같은 이름 금지**. **가져오기에서 이름이 겹치면 경고** → `덮어쓰기` / `이름 바꿔서 가져오기` / 취소 |
| 비공개 표시 | `{{ }}` · `:::비공개` — 보라색·자물쇠·블러, AI 로 가는 모든 길에서 가림, AI 수정으로 지워지지 않음 |
| **노트 바로 수정** | AI 가 `edit_page`/`create_page` 로 바로 고침 → 바뀐 블록 강조 + 페이지 위 막대와 채팅 카드에 `되돌리기 | 확정`. 둘 다 안 누르면 **Ctrl+Z = 되돌리기, Ctrl+S = 확정**. 직접 고쳐 저장하면 강조만 사라짐(채팅에서 계속 되돌릴 수 있음). 그 뒤 다른 곳을 고쳤으면 AI 가 바꾼 부분만 되돌리고, 같은 곳을 고쳤으면 경고 후 "그래도 되돌리기" |
| **노트 지목** | 채팅에서 "OO프로젝트의 OO노트 확인해줘" → 서버가 제목·프로젝트로 찾아 내용을 함께 보냄 (AI 도구 `find_page` 도 있음). 그 노트는 대화의 **다루는 노트**로 남아 질문마다 최신 내용을 다시 보냄 → "거기에 추가해줘" 가 그 노트. 입력창 위 칩, ×로 빼기 |
| **로그인** | 공용 계정(아이디 + 암호, 암호는 `.env.auth` 에 해시로만). "이 기기에서 로그인 유지"(30일), 설정의 "모든 기기에서 로그아웃", 5번 틀리면 15분 잠금 |
| 프레젠테이션 | 편집기·슬라이드 쇼, AI 가 바로 수정 + 되돌리기 (나머지는 보류) |

## 배포 메모 (Vultr, 나중)
- 도메인: 지금은 한국 도메인을 직접 만들어 쓰고, 운영이 안정되면 정식 도메인 계약
- nginx(HTTPS, Let's Encrypt) → gunicorn(127.0.0.1) 구성. `.env` 에 `TRUST_PROXY=true`, `SESSION_COOKIE_SECURE=true`, 긴 `SECRET_KEY`
- 서버에서 `flask --app run set-login` 으로 `.env.auth` 만들기 (암호는 해시로만 저장, 권한 600)
- SSH 는 키 로그인만(암호 로그인 끄기), `ufw` 로 22·80·443 만 열기, `fail2ban`
- Claude Code 는 서버를 실행하는 OS 사용자로 `claude` 로그인 (구독). 다른 사람도 쓰게 되면 구독 약관상 공유 계정 주의 (사용자 동의함)
- DB·첨부·대화 파일(`instance/`) 정기 백업
