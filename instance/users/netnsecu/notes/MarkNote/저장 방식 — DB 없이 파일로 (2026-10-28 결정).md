**이 프로젝트는 DB 를 쓰지 않는다.** 노트는 폴더와 `.md` 파일, 나머지는 JSON 파일이다.
예전 SQLite(`instance/marknote.db`)는 한 번만 읽어서 파일로 옮기고(`flask --app run import-db`) 더는 쓰지 않는다.

## 폴더 구조
```
instance/
  notes/                       ← 노트 (메모장·VS Code·옵시디언으로 열어도 됨)
    회사/                      ← 프로젝트 = 폴더 (자기 내용 없음)
      회의록.md                ← 노트
      회의록/                  ← 노트 아래 노트 ("회의록.md" 와 같은 이름의 폴더)
        3월.md
    분류 안 됨/                ← 프로젝트 밖에 놓일 노트 (낱개 .md 가져오기, 부모 없이 복원)
    .archive/회사/…            ← 보관함 (원래 경로 그대로 아래에)
    .trash/회사/…              ← 휴지통
    .marknote/index.json       ← 앱 전용: 페이지 번호·순서·휴지통 시각 (지워도 노트는 그대로, 번호만 새로 매김)
  uploads/<uuid>.<확장자>      ← 그림 (/files/<uuid>)
  decks/<번호>.json            ← 프레젠테이션 (슬라이드 포함 한 파일)
  ai-chats/<대화>.jsonl        ← AI 대화 기록 (원래 파일)
  ai-edits/<번호>.json         ← AI 수정 기록 (되돌리기·확정용)
  settings.json                ← 설정 화면 값, 로그인 세대(모든 기기 로그아웃)
  ai-usage.json                ← 날짜별 AI 사용량
```

## 노트 파일
- **제목 = 파일 이름** (확장자 제외). 파일 이름에 못 쓰는 글자(`\ / : * ? " < > |`)는 빠진다. 제목을 바꾸면 파일(과 하위 폴더) 이름이 바뀐다
- 아이콘만 앞머리에: `---\nicon: 📘\n---` (없으면 앞머리 없음). 본문은 그대로 마크다운
- 같은 폴더 안에 같은 이름 금지 (대소문자·공백 무시) — 파일 시스템과 같은 규칙
- 순서: `index.json` 의 순서값, 없으면 이름순
- 노트 아래 노트는 부모 본문 끝에 `[[page:번호]]` 링크 블록 (프로젝트에는 없음)
- 앱 밖에서 파일을 더하거나 고치면: 다음 화면부터 그대로 보임 (새 파일엔 번호를 새로 매김). 앱 밖에서 이름을 바꾸면 번호가 새로 매겨져 예전 주소(`/p/번호`)는 없어짐

## 블록 편집기
- 블록 = 본문을 빈 줄로 나눈 조각. 블록 번호는 **서버 메모리**에만 있다 (파일엔 없음)
- 저장할 때마다 파일 전체를 다시 쓴다 (임시 파일에 쓴 뒤 바꿔치기 — 중간에 꺼져도 파일이 깨지지 않음)
- 앱 밖에서 파일이 바뀌었는데 편집기가 예전 블록 번호로 저장하면 409 → "다시 불러오기"

## AI 계획 (파일 기준으로 다시 세움)
- **AI 는 파일을 직접 열지 않는다.** Claude Code 의 파일 도구(Read·Edit·Grep)는 계속 끈다(`--tools ""`).
  파일을 직접 읽게 하면 `{{ }}`·`:::비공개` 를 가릴 방법이 없기 때문 → 모든 읽기·쓰기는 MarkNote MCP 도구로만
- 도구는 그대로, 위치를 파일 경로로 알려 준다
  - `list_pages` / `search_pages` / `find_page("회사 / 회의록")` / `read_page` → 결과마다 `file: "회사/회의록.md"` (프로젝트는 `"회사/"`)
  - `edit_page` / `create_page` → 파일에 바로 쓰고 수정 기록(`ai-edits/`)을 남김 → 채팅·페이지에서 `되돌리기 | 확정` (Ctrl+Z / Ctrl+S)
  - 프로젝트(폴더)에는 내용을 쓸 수 없음, 노트는 프로젝트 안에만
- 질문마다 지금 노트·다루는 노트를 **파일에서 새로 읽어** 보낸다 → 앱 밖(VS Code 등)에서 고친 내용도 반영
- 페이지 강조는 파일 내용이 AI 가 쓴 그대로일 때만 (직접 고쳐 저장하면 저절로 사라짐, 기록에는 바뀐 블록 위치만)
- 되돌리기는 블록 내용 기준 3-way 비교 (파일이 그 뒤 바뀌었어도 AI 가 바꾼 부분만 되돌림)
- 대화 기록은 지금처럼 파일. "나중에 SQLite 로" 계획은 **취소** → 많이 쌓이면 오래된 대화를 `ai-chats/archive/` 로 옮기는 정리만
- MCP 서버는 따로 뜨는 프로세스라, 공유 파일(`index.json`, `ai-edits/`)은 잠금 파일 + 바꿔치기 쓰기로 동시에 써도 깨지지 않게

## 예전 DB 옮기기 (한 번)
```bash
flask --app run import-db instance/marknote.db
```
- DB 는 읽기만 한다 (지우거나 바꾸지 않음). 노트·그림·프레젠테이션·설정·사용량·AI 수정 기록을 위 구조로 쓴다
- 페이지 번호를 그대로 쓴다 → `[[page:N]]` 링크·`/p/N` 주소가 계속 맞음
- 예전에 프로젝트(최상위 페이지)에 직접 쓴 내용은 그 프로젝트 안 `개요.md` 로
- 예전 "AI 수정 제안"(승인 방식)은 더 쓰지 않아 옮기지 않는다
- 이미 `instance/notes/` 에 노트가 있으면 멈춤 (덮어쓰지 않음)
