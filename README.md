# 📝 MarkNote (가칭)

> Flask 기반의 개인용 노션 스타일 마크다운 노트
> 허용된 계정만 접속할 수 있고, 노트를 그냥 폴더와 `.md` 파일로 관리하며, 줄/블록 단위로 "편집 중엔 마크다운 → 완료하면 미리보기"로 바뀌는 편집기를 제공합니다.
> YouTube 링크는 자동으로 플레이어로 바뀌고, 이미지는 붙여넣기/드래그로 올릴 수 있습니다.

진행 현황·남은 일: [docs/roadmap.md](docs/roadmap.md)

**계정과 탐색기**: 계정마다 자기 노트만 봅니다 (`instance/users/<아이디>/notes/`). 왼쪽 사이드바는 VS Code 탐색기처럼 그 폴더를 그대로 보여 줍니다 — 폴더(깊이 제한 없음)와 노트(`.md`)뿐이고, 맨 위에도 노트를 둘 수 있으며 `README.md` 도 그냥 노트입니다. 화면 주소도 경로 그대로(`/n/회사/회의록.md`). 같은 폴더 안에는 같은 이름을 둘 수 없습니다. 전체 기능 정리: [marknote_project.md](marknote_project.md). 가져오기에서 이름이 겹치면 `덮어쓰기`(기존 것은 휴지통으로) 또는 `이름 바꿔서 가져오기`를 고릅니다.

## 1. 프로젝트 개요

| 항목 | 내용 |
|---|---|
| 목적 | 혼자 쓰는 비공개 노션 대체 — 자료가 외부에 공유되지 않아야 함 |
| 운영 환경 | **라즈베리파이** (Raspberry Pi OS 64-bit) — [9장](#9-라즈베리파이-배포) 참고 |
| 언어 / 프레임워크 | Python 3.11+, Flask 3.x |
| 저장 | 노트는 **파일** — `instance/users/<아이디>/notes/<폴더…>/<노트>.md`, 나머지는 JSON 파일. **SQLite 는 계정·로그인 잠금 기록만** (`instance/accounts.db`) ([docs/storage.md](docs/storage.md)) |
| 인증 | 현재: 계정별 로그인(관리자가 CLI 로 계정 생성, 해시 암호, 기기별 로그인 유지) → 나중: OTP 등 — [3장](#3-접근-제어-인증) 참고 |
| 프론트엔드 | Jinja2 템플릿 + Vanilla JS (외부 CDN 없음) |
| 마크다운 렌더링 | 서버 한 곳에서만: `Markdown` + `Pygments`(코드 하이라이트) → `bleach` 정화. 블록 저장 시 렌더링된 HTML을 돌려받아 즉시 표시 |
| 보안 | `bleach`로 렌더링 결과 HTML 정화(XSS 방지), CSRF 보호(Flask-WTF) |

## 2. 핵심 기능

### 2.1 폴더 & 노트 (그냥 디렉토리)
- 계정의 `notes/` 폴더 = 탐색기 맨 위. **폴더**(깊이 제한 없음)와 **노트**(`.md` 파일)만, 맨 위에도 노트를 둘 수 있음. 노트 아래에 노트는 없음 — 묶으려면 폴더
- 새 파일은 언제나 `.md`. 노트 파일은 **순수 본문**만 (앞머리·아이콘 없음). `README.md` 도 보통 노트
- **폴더 화면은 없음** — 폴더를 누르면 탐색기에서 펼치고 접기만
- **화면 주소 = 파일 경로**: `/n/회사/회의록.md` (이름을 바꾸면 주소도 바뀜 — 없는 주소는 홈으로 가서 가장 가까운 상위 폴더를 탐색기에서 보여 줌)
- 화면 이동은 **새로고침 없이** 본문만 바꿔서 (사이드바 펼침·AI 패널 그대로, 뒤로가기 동작)
- **노트끼리 링크 = 상대 경로** `[회의록](../회의록.md)` — VS Code·GitHub 에서도 그대로 동작. 앱에서 이름을 바꾸거나 옮기면 그 노트를 가리키는 링크를 모든 노트에서 함께 고침. 없는 노트를 가리키면 취소선으로 표시
- 이동 수단
  - **탐색기** (VS Code 와 같은 조작): 클릭·Ctrl/Shift 클릭 선택, 방향키·Home/End·Enter, Delete(휴지통), Ctrl+C/X/V(복사·잘라내기·붙여넣기), Ctrl+A, 끌어서 옮기기(Ctrl/Alt = 복사), 우클릭 메뉴(새 파일·새 폴더·이름 바꾸기·복사·보관·휴지통·가져오기·경로 복사). 이름은 그 자리 입력칸에서. F2 는 AI 도우미 열기 (이름 바꾸기는 우클릭)
  - **브레드크럼**: `회사 / 2026-03 / 3월 회의` — 상위 폴더로 바로 이동
  - **이전/다음 버튼**: 같은 폴더 안 노트끼리
- 순서는 `index.json` 에 저장, 앱 밖에서 새로 생긴 파일은 맨 뒤

### 2.2 보관 & 삭제
- **보관(Archive)**: 목록에서 숨기고 보관함으로 이동, 복원 가능
- **삭제(Trash)**: 휴지통으로 이동(소프트 삭제) → 복원 또는 영구 삭제
- 폴더를 보관/삭제하면 **안의 것도 함께** 이동 (복원 시 함께 복원). 원래 폴더가 없어졌으면 같은 이름으로 다시 만들어 그 안으로

```
[활성] ──보관──▶ [보관함] ──복원──▶ [활성]
   │                 │
   └──삭제──▶ [휴지통] ◀──삭제──┘
                 │
           복원 / 영구삭제
```

### 2.3 블록 편집기 (라이브 프리뷰) ⭐
노션·Obsidian 라이브 프리뷰처럼 **편집 중인 블록만 마크다운 원문**, 나머지는 렌더링된 결과로 표시합니다.

```
  # 회의록                       ← 렌더링 (큰 제목으로 보임)
  오늘 논의한 내용은...            ← 렌더링
┃ - [ ] **API** 설계 마무리      ← 커서가 있는 블록: 마크다운 원문 그대로
  https://youtu.be/xxxxxxxxxxx  → (렌더링 시 ▶ 플레이어)
```

동작 규칙:
| 동작 | 결과 |
|---|---|
| 블록 클릭 | 해당 블록이 마크다운 원문(textarea)으로 전환 |
| 다른 곳 클릭 / `Esc` | 편집 완료 → 즉시 렌더링 모드로 전환 + 저장 |
| `Enter` (일반 문단) | 커서 위치에서 블록을 나눔 → 아래 새 블록 편집 |
| `Shift+Enter` | 블록 안에서 줄바꿈 |
| 빈 블록에서 `Backspace` | 블록 삭제, 위 블록으로 이동 |
| `↑` / `↓` (블록 첫/끝 줄) | 위/아래 블록 편집으로 이동 |
| 내용을 모두 지우고 완료 | 블록 삭제 |
| 블록 맨 앞에서 `Backspace` | 위 블록과 합치기 |
| `Enter` (목록/인용 줄 끝) | 다음 항목 자동 이어쓰기 (`- `, `1.`, `- [ ] `, `> `), 빈 항목에서 한 번 더 누르면 목록 종료 |
| `Tab` / `Shift+Tab` | 들여쓰기 / 내어쓰기 |
| `Esc` / `Ctrl+S` | 편집 완료 |

- 블록 단위: 문단, 제목, 목록, 체크리스트, 인용, 코드블록, 표, 구분선, 이미지, 영상
- 블록 하나 = 빈 줄로 구분되는 마크다운 덩어리. 여러 문단을 붙여넣으면 저장 시 자동으로 여러 블록으로 나뉨
- 코드블록(```) 안에서는 Enter가 줄바꿈이고, 빈 줄이 있어도 하나의 블록으로 유지
- 표(`|`로 시작하는 줄) 작성 중에도 Enter는 줄바꿈
- 체크박스는 보기 모드에서 바로 클릭해 체크/해제 (원문의 `[ ]` ↔ `[x]` 갱신)
- 블록 왼쪽 `⋮⋮` 핸들로 드래그해 순서 변경, 오른쪽 `✕`로 삭제
- 한글 입력(IME 조합) 중 Enter는 무시해 글자가 잘리지 않음
- 자동 저장: 입력하다 1초 멈추면 편집 중인 블록을 그대로 저장(`split:false`, 빈 줄이 있어도 나누지 않음), 편집을 마치면 다시 저장하면서 블록 나누기. 제목도 입력 0.8초 뒤 저장 → AI 도우미가 늘 최신 내용을 읽음
- 전체 원문 보기/편집 모드(`✏️ 원문 편집`) 제공 (긴 글 붙여넣기용)

### 2.4 영상 임베드 (YouTube 우선)
한 줄 전체가 영상 링크면 플레이어로 변환합니다. 문장 중간의 링크는 일반 링크로 유지합니다.

YouTube 지원 형식:
| 형식 | 예시 |
|---|---|
| 일반 / 모바일 | `https://www.youtube.com/watch?v=ID`, `https://m.youtube.com/watch?v=ID` |
| 단축 | `https://youtu.be/ID` |
| 쇼츠 | `https://www.youtube.com/shorts/ID` |
| 시작 시간 | `&t=90`, `&t=1m30s` |
| 재생목록 | `https://www.youtube.com/playlist?list=...` (2차) |

- `ID`는 `[A-Za-z0-9_-]{11}`로 검증, `youtube-nocookie.com`으로 임베드
- 브라우저 정책상 소리 있는 자동재생은 막히므로 **문서 안 플레이어 + 클릭 한 번 재생**
- **확장 구조**: `EmbedProvider` 레지스트리로 설계 → Vimeo, 치지직, 네이버TV 등은 나중에 provider 하나만 추가하면 됨 (당장은 YouTube만 구현)

### 2.5 이미지
- 업로드 방법: **클립보드 붙여넣기(Ctrl+V)**, **드래그 앤 드롭**, 파일 선택 버튼
- 업로드 즉시 이미지 블록 `![](/files/<uuid>)` 삽입
- 허용 형식: png, jpg, gif, webp (Pillow로 실제 이미지인지 검증, SVG는 XSS 위험으로 제외)
- 최대 용량 10MB (설정 가능), 파일명은 UUID로 저장
- 저장 위치 `instance/uploads/` — **static이 아닌 로그인 필요 라우트로만 제공** (URL을 알아도 비로그인은 못 봄)
- 이미지 클릭 시 원본 크게 보기, 너비 조절 (2차)

### 2.6 마크다운 가져오기 / 내보내기
**내보내기 (다운로드)**
| 위치 | 형식 | 내용 |
|---|---|---|
| 노트 `⋯` 메뉴 | `.md` | 그 노트 파일 그대로 (이미지는 `/files/...` 주소) |
| 노트·폴더 `⋯` 메뉴 | `.zip` | 폴더 구조 그대로 + 이미지. 링크는 상대 경로라 다른 앱에서도 동작 |
| 사이드바 `📦 전체 내보내기` | `.zip` | 그 계정의 활성 노트 전체 (백업용) |

zip 구조 (계정의 `notes/` 와 같은 모양):
```
프로젝트/README.md          ← 보통 노트
프로젝트/설계.md
프로젝트/설계 자료/API.md
images/<uuid>.png          ← 각 문서에서 상대 경로로 참조
```

**가져오기**
- 탐색기 빈 곳 우클릭 `가져오기` → 맨 위로, 폴더 우클릭 `이 폴더로 가져오기` → 그 폴더 안으로. 탐색기에 파일을 끌어다 놓아도 됨
- 노트에 `.md`/`.zip` 파일을 **끌어다 놓으면** 그 노트가 있는 폴더로 가져옴
- 지원: `.md`, `.markdown`, `.txt` (여러 개 동시 선택 가능), `.zip`
- 이름 = 파일·폴더 이름. 앞머리(`---`)와 파일 이름과 같은 첫 줄 `# 제목` 은 빼고 본문만
- zip 안 폴더 구조 그대로, `README.md` 도 보통 노트. 상대 링크는 새 위치에 맞게 고치고, 상대 경로 이미지는 업로드해서 연결
- **노션 내보내기 zip** 도 가져올 수 있음 (zip 안의 zip, 이름 끝의 노션 ID 제거, `X.md` + `X/` 짝은 폴더 `X` + 그 안 노트 `X`)
- 한글 처리: 윈도우 메모장(cp949) 파일, 윈도우 탐색기로 만든 zip의 한글 파일명, macOS zip(NFD) 모두 지원
- 안전장치: 요청 하나 최대 100MB, zip 압축 해제 합계 300MB·파일 5000개 제한, 이미지는 실제 이미지인지 검증

## 3. 접근 제어 (인증)

목표: **나(허용된 계정)만 접속**, 회원가입 없음, 문서·이미지 모두 로그인 없이는 접근 불가.

### 후보 방안 비교

| # | 방안 | 장점 | 단점 | 적합한 경우 |
|---|---|---|---|---|
| A | **ID/PW + 허용 계정 (CLI로만 계정 생성)** | 구현 간단, 외부 의존 없음 | 비밀번호 유출 시 위험 | 내 PC에서만 사용 |
| B | **A + 2단계 인증(TOTP, Google Authenticator 등)** | 비밀번호가 털려도 OTP 없으면 차단, 외부 의존 없음 | 로그인 시 OTP 입력 필요 | 외부(폰, 회사)에서도 접속 ⭐추천 |
| C | **Google 로그인(OAuth) + 이메일 allowlist** | 비밀번호 관리 불필요, Google의 2FA 그대로 활용 | Google Cloud 설정 필요, 인터넷 필수 | 이미 Google 2FA 사용 중일 때 |
| C' | **네이버 로그인(OAuth) + 네이버 고유 ID allowlist** | 비밀번호 관리 불필요, 네이버 2단계 인증 활용, 한국 사용자에게 익숙 | developers.naver.com 앱 등록·콜백 URL 등록 필요, 인터넷 필수 | 평소 네이버 계정을 주로 쓸 때 |
| D | **네트워크 단에서 차단** (127.0.0.1 바인딩 / Tailscale / Cloudflare Access) | 앱 자체가 외부에 노출 안 됨 | 앱 밖의 설정 필요 | A~C와 **함께** 쓰는 추가 방어막 |

### 현재 상태: 계정별 로그인 ✅ 구현됨 (2026-10-31)
- 계정은 **SQLite**(`instance/accounts.db`)에, 비밀번호는 해시로만. **가입 화면 없음** — 관리자가 서버에서 만든다:
  ```bash
  flask --app run add-user mina
  ```
  `--admin` 을 붙이면 관리자. 그 밖에 `set-password <아이디>`, `list-users`, `remove-user <아이디>` (지워도 노트 폴더는 남음)
- **계정마다 보이는 파일이 다름**: 노트·그림·프레젠테이션·AI 대화·AI 수정 기록·설정 모두 `instance/users/<아이디>/` 아래. 관리자도 앱에서 다른 계정의 노트를 볼 수 없음
- **처음 켤 때**: 계정이 하나도 없으면 `.env.auth` 의 `LOGIN_USER`/해시(없으면 로컬 개발용 `ACCESS_PASSWORD`)로 관리자 계정을 만들고, 예전 위치(`instance/notes` 등)의 데이터를 `instance/backups/before-accounts-<시각>/` 에 **백업한 뒤** 그 계정 폴더로 옮김
- **"이 기기에서 로그인 유지"** 체크 → 그 브라우저만 30일 유지. 안 하면 브라우저를 닫을 때 로그아웃 (공용 PC)
  - IP 로 판단하지 않음 — 같은 와이파이·회사망을 쓰는 다른 사람까지 들어오게 되므로
- 설정 → **"모든 기기에서 로그아웃"**: 그 계정이 다른 기기에 남긴 로그인까지 모두 끊음 (비밀번호를 바꿔도 끊김)
- 로그인 화면 외 모든 라우트는 로그인 필요 (`before_request` 전역 검사)
- 로그인 실패 5회 → 15분 잠금 (IP 기준, DB 에 기록 — 서버를 다시 켜도 유지)
- Claude 로그인(`/login`·`/logout`)은 서버에 하나라 **관리자만** 바꿀 수 있음. AI 답변은 질문한 계정만 이어 받고 멈출 수 있음
- CSRF 보호 (토큰은 로그인 세션 동안 유효 — 1시간마다 뜨던 "CSRF token has expired" 없음), 세션 쿠키 `HttpOnly`/`SameSite=Lax`, 외부 사이트로의 `next` 리다이렉트 차단
- ⚠️ 서버(Vultr)에 올릴 때는 `SECRET_KEY` 를 긴 랜덤 값으로, `SESSION_COOKIE_SECURE=true`, 프록시 뒤면 `TRUST_PROXY=true`

### 최종 인증 후보 (결정 필요)
**네이버 로그인(C')** 은 충분히 쓸 만합니다.
- 네이버 개발자센터에서 "네이버 로그인" 앱 등록 → Client ID/Secret 발급
- 로그인 후 받는 **네이버 고유 식별자(id)** 를 allowlist에 등록해 그 계정만 통과 (이메일은 사용자가 변경할 수 있어 고유 id 기준이 안전)
- 앱을 검수 요청 없이 "개발 중" 상태로 두면 **등록한 멤버(테스터) 계정만 로그인 가능** → 이것만으로도 이중 잠금 효과
- 콜백 URL이 등록돼 있어야 하므로 접속 주소(예: Tailscale 주소 `https://pi.xxx.ts.net/auth/naver/callback`)를 먼저 정해야 함
- 네이버 장애·인터넷 단절 시 로그인 불가 → 비상용 로컬 로그인(B) 하나는 남겨두는 것을 권장

공통 원칙:
- 회원가입 페이지 없음, 비밀값은 `.env`로 분리(git 제외)
- 모든 페이지·API·이미지 라우트 로그인 필요
- 외부 접속은 공유기 포트 개방 대신 **Tailscale** 권장

## 5. 라우트 설계

### 페이지 (모두 로그인 필요, 로그인 화면 제외)
| Method | URL | 설명 |
|---|---|---|
| GET/POST | `/login` | 로그인 (ID/PW → OTP) |
| POST | `/logout` | 로그아웃 |
| GET | `/` | 홈 (최근 페이지) |
| GET | `/n/<경로>` | 노트 보기/편집 (`/n/회사/회의록.md`), 폴더 보기 (`/n/회사/`) |
| GET | `/p/<id>` | 앱 안쪽 번호 주소 → 경로 주소로 보냄 (보관함·휴지통 안은 여기서 보기) |
| GET | `/archive` | 보관함 |
| GET | `/trash` | 휴지통 |
| GET | `/files/<uuid>` | 이미지 제공 (로그인 필요) |
| GET | `/local` | 내 PC 폴더 편집 (노트는 브라우저가 PC 에서 직접 읽고 씀, 서버 저장 없음) |

### API (JSON, CSRF 토큰 필요)
| Method | URL | 설명 |
|---|---|---|
| POST | `/api/pages` | 폴더·노트 생성 (`parent_id` 폴더 안에, `kind: folder`/`note`(기본), `parent_id` 가 없으면 맨 위) |
| PATCH | `/api/pages/<id>` | 이름(= 파일 이름)·부모 폴더·순서(`order`) 변경 — 링크도 함께 고침 |
| POST | `/api/pages/<id>/copy` | 복사본 만들기 (`parent_id` 폴더 안에, 없으면 맨 위). 폴더는 안의 것까지, 함께 복사된 노트끼리 링크는 복사본을 가리킴 |
| POST | `/api/pages/<id>/archive` · `/restore` · `/trash` | 상태 변경 (하위 포함) |
| DELETE | `/api/pages/<id>` | 영구 삭제 (휴지통 상태에서만) |
| POST | `/api/trash/empty` | 휴지통 비우기 |
| POST | `/api/pages/<id>/blocks` | 블록 추가 (`after_id` / `before_id` 로 위치 지정) |
| PATCH | `/api/blocks/<id>` | 블록 내용 수정 (빈 줄이 있으면 여러 블록으로 분할) |
| DELETE | `/api/blocks/<id>` | 블록 삭제 |
| POST | `/api/pages/<id>/blocks/reorder` | 블록 순서 변경 |
| GET / PUT | `/api/pages/<id>/source` | 페이지 전체 마크다운 원문 조회 / 교체 |
| POST | `/api/uploads` | 이미지 업로드 |
| POST | `/api/import` | `.md`/`.zip` 가져오기 (`files`, 선택: `parent_id`) |

### 내보내기 (파일 다운로드)
| Method | URL | 설명 |
|---|---|---|
| GET | `/export/page/<id>.md` | 페이지 하나를 .md 로 |
| GET | `/export/page/<id>.zip` | 폴더 구조·이미지 포함 zip |
| GET | `/export/all.zip` | 전체 내보내기 |

## 9. 실행 방법

### 개발 (Windows PC)
```bash
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
copy .env.example .env          # SECRET_KEY, ACCESS_PASSWORD 설정
python run.py
```
→ http://127.0.0.1:5000 접속, 암호 입력 (기본 `temp`)

테스트: `pip install pytest` 후 `python -m pytest`

### 라즈베리파이 배포
```bash
sudo apt install python3-venv git
git clone <저장소> ~/marknote && cd ~/marknote
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env && nano .env      # 비밀값 변경 필수
gunicorn -w 2 -b 127.0.0.1:8000 run:app
```
운영 권장 구성:
- **systemd 서비스**로 등록해 부팅 시 자동 실행
- 앞단에 **Caddy**(또는 nginx) 리버스 프록시 → HTTPS 처리, `SESSION_COOKIE_SECURE=true`
- 외부 접속은 **Tailscale** (포트 개방 불필요, `tailscale cert`로 HTTPS 인증서 발급 가능)
- `instance/` 폴더(노트 .md·그림·설정)는 **주기적 백업**(USB/SSD 또는 NAS로 cron 복사)
- 가능하면 SD카드 대신 USB SSD 부팅 권장
- gunicorn 워커가 2개 이상이면 로그인 실패 잠금 기록이 워커마다 따로 저장됨 → 정식 인증 단계에서 파일 저장으로 변경 예정

## 10. AI 도우미 (Claude Code 구독 계정)

사이드바 `✨ AI 도우미` / 페이지 상단 `✨ AI` 로 여는 채팅 패널. 서버에 설치된 공식 Claude Code CLI를 `claude -p` 로 실행하며 **API 요금이 아닌 구독 사용량**으로 동작합니다.

사용 준비 (서버 컴퓨터에서 한 번):
1. Claude Code 설치 — Windows: `irm https://claude.ai/install.ps1 | iex` / 라즈베리파이: `curl -fsSL https://claude.ai/install.sh | bash`
2. 로그인
   - 서버와 **같은 컴퓨터**의 브라우저라면: 채팅 입력창에 `/login` → 표시된 Anthropic 링크에서 로그인
   - 원격 접속이라면: 서버 터미널(SSH)에서 **서버를 실행하는 같은 사용자**로 `claude` 실행 → 로그인
   - (또는 `claude setup-token` 결과를 `.env` 의 `CLAUDE_CODE_OAUTH_TOKEN` 에)
3. 패널의 상태 배지가 초록 "연결됨" 이면 완료. 해제는 `/logout`, 확인은 `/status`

설정(`⚙️ 설정`)에서 할 수 있는 것:
- **초기 프롬프트**: 모든 대화에 항상 적용할 지침 (말투, 답변 형식 등)
- **노트 읽기**: Claude 가 다른 페이지도 검색·읽기
- **노트 바로 수정**: "고쳐줘" 같은 요청에 AI 가 노트를 바로 고침 → 바뀐 블록이 파랗게 강조되고 페이지 위·채팅 카드에 **`되돌리기 | 확정`**
  - 둘 다 안 누르면 **Ctrl+Z = 되돌리기**, **Ctrl+S = 확정**. 직접 고쳐 저장하면 강조만 사라짐 (채팅 카드에서 계속 되돌릴 수 있고, 내가 고친 부분은 남김)
- **노트 삭제 = 휴지통으로**: "이 노트 지워줘" → AI 가 노트·폴더를 휴지통(`notes/.trash/`)으로 옮김. 영구 삭제는 못 함. 채팅 카드 `되돌리기` = 원래 자리로 복원 (설정에서 끌 수 있음)
- **노트 지목**: "OO폴더의 OO노트 확인해줘" 처럼 이름으로 부르면 그 노트를 찾아 읽음. 그 노트는 입력창 위 **다루는 노트**로 남아 "거기에 추가해줘" 가 그 노트를 가리킴 (× 로 빼기)
- **프레젠테이션 바로 수정**: 슬라이드는 AI 가 바로 고치고 채팅 카드의 [되돌리기]로 취소

**대화는 페이지를 옮겨도 그대로 이어집니다.** 대화 기록은 서버의 `instance/ai-chats/` 에 파일(JSONL)로 남고, 답변 중에 다른 페이지로 가도 답은 서버에서 끝까지 만들어져 새 페이지에서 이어 받습니다. 새로 시작하려면 패널의 `새 대화`(또는 `/new`). 예전 대화는 패널의 `기록` 버튼이나 `/resume`(검색: `/resume 회의`)으로 골라 이어 가고, `/rename 이름`(지금 대화) 또는 목록의 연필 버튼(아무 대화나)으로 이름을 붙일 수 있습니다.

**AI 에게 보이지 않게 하기**: 노트에서 `{{계좌번호}}` 처럼 감싸거나(블록 편집 중 `Ctrl+Shift+H`), 블록 우클릭 → `비공개로` 를 고르면 그 부분은 흐리게 보이고(눌러서 보기) AI 에게는 보내지 않습니다. AI 가 페이지를 고쳐도 그 부분은 지워지거나 바뀌지 않습니다.

채팅 입력창 아래 오른쪽에는 **사용 중인 모델 · 노력 수준 · 사용량 고리**가 보입니다 (예: `Opus 5.5 중간 ◔`).
- 모델 이름을 누르면 모델(기본·Opus·Sonnet·Haiku·Fable)과 노력 수준(기본~최대)을 바꿀 수 있음 — 다음 질문부터 적용
- 고리는 구독 사용 한도(5시간) 사용률 — Claude Code 가 알려 주지 않았으면 이 대화의 컨텍스트 사용률. 누르면 5시간·주간 한도와 재설정 시각, 이 대화 컨텍스트, 오늘 이 앱에서 쓴 질문 수·토큰

Claude 는 MarkNote 노트에만 접근하며 PC 의 다른 파일이나 명령 실행에는 접근할 수 없습니다.
앱은 Claude 로그인을 직접 처리하거나 토큰을 입력받지 않습니다 (Anthropic 정책). 자세한 설계·정책은 [docs/claude-integration.md](docs/claude-integration.md).
