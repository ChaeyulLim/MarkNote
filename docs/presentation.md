# 온라인 PPT (프레젠테이션) 기획

> 상태: **1단계(뼈대) 구현 완료** — 2단계(파일)부터 남음. 구현 현황은 맨 아래 "14. 구현 현황"
> 기준: **Microsoft PowerPoint** 의 화면 구성·용어·단축키·동작을 따른다. PowerPoint 를 쓰던 사람이 설명 없이 쓸 수 있는 것이 목표.
> 범위: 1차는 **만들고·편집하고·발표하는 핵심 도구**. 테마·전환·애니메이션·효과 같은 **꾸미기는 이후 단계**로 분리한다.
> 대상: **PC 버전 (데스크톱 브라우저, 마우스·키보드)** 만. 휴대폰·태블릿 화면과 휴대폰 리모컨 등은 제외 (나중에 별도 검토).
> AI: Claude 에이전트가 프레젠테이션을 **직접 편집**한다 — 요청하면 **바로 슬라이드에 적용**되고, 채팅의 [되돌리기]로 취소 (12장, 구현됨).
> (노트는 "제안 → [적용]" 방식 그대로. 슬라이드는 "조언만으로는 의미가 없다"는 결정에 따라 바로 적용으로 바꿈, 2026-10-27)

- 노트와 **별도의 공간**. 사이드바 맨 위를 `노트 | 프레젠테이션` 탭으로 나눈다.

## 2. 화면 구성 (PowerPoint 기본 보기)

```
┌────────────────────────────────────────────────────────────────────────┐
│ 파일  [홈]  삽입  슬라이드 쇼  보기                      제목     ▶ 쇼   │ ← 리본 탭
├────────────────────────────────────────────────────────────────────────┤
│ 새 슬라이드▾ 레이아웃▾ │ 글꼴 크기 B I U S 색 │ 정렬 글머리표 │ 도형 정렬 │ ← 리본 (그룹별)
├───────┬────────────────────────────────────────────────────────────────┤
│  1 ▭  │                                                                │
│  2 ▭  │                    슬라이드 편집 창 (16:9)                       │
│▶ 3 ▭  │                                                                │
│  4 ▭  │                                                                │
│       ├────────────────────────────────────────────────────────────────┤
│       │ 슬라이드 노트를 입력하려면 클릭하십시오                           │ ← 노트 창
├───────┴────────────────────────────────────────────────────────────────┤
│ 슬라이드 3/12 │ 한국어 │            노트 │ ▦ 기본 ▦ 여러 슬라이드 ▶ │ ─●─ 76% ⤢ │ ← 상태 표시줄
└────────────────────────────────────────────────────────────────────────┘
```

| 영역 | PowerPoint 와 같은 동작 |
|---|---|
| 리본 | 탭(홈·삽입·슬라이드 쇼·보기) + 그룹 단위 버튼, 창이 좁으면 그룹이 접힘 |
| 축소판 그림 창 (왼쪽) | 슬라이드 번호·미리보기, 클릭 선택, 드래그 순서 변경, Shift/Ctrl 다중 선택, 우클릭 메뉴 |
| 슬라이드 창 (가운데) | 개체 선택·이동·크기 조절·회전, 개체 틀(placeholder) 안내 문구 |
| 노트 창 | 슬라이드별 발표자 노트, 경계선 드래그로 높이 조절 |
| 상태 표시줄 | 현재 슬라이드 번호, 노트 창 토글, 보기 전환, 확대/축소 슬라이더, 창에 맞춤 |
| 서식 창 (오른쪽, 필요할 때) | 우클릭 → "도형 서식" 등으로 여는 세부 설정 창. 1차는 위치·크기·채우기·선만 |

## 4. 슬라이드 레이아웃 (PowerPoint 기본 Office 테마와 같은 9종)

제목 슬라이드 · 제목 및 내용 · 구역 머리글 · 콘텐츠 2개 · 비교 · 제목만 · 빈 화면 · 캡션 있는 콘텐츠 · 캡션 있는 그림

- 각 레이아웃은 **개체 틀**로 구성: "제목을 입력하려면 클릭하십시오", "텍스트를 입력하려면 클릭하십시오"
- 개체 틀이 비어 있으면 편집 화면에만 안내 문구가 보이고, 쇼·내보내기에서는 보이지 않음
- 레이아웃 변경 시 내용은 유지하고 개체 틀 위치만 다시 배치 (PowerPoint 의 "레이아웃" 동작)
- "다시 설정": 개체 틀 위치·크기·서식을 레이아웃 기본값으로

## 5. 개체 (1차)

| 개체 | 내용 |
|---|---|
| 텍스트 상자 / 개체 틀 | 서식 있는 텍스트(글꼴·크기·굵게·기울임·밑줄·취소선·색), 단락(맞춤·글머리 기호·번호·수준 1~5·줄 간격), 자동 맞춤(텍스트에 맞게 도형 크기 조정 / 넘치면 글자 축소), 세로 맞춤 |
| 도형 | 사각형 · 둥근 사각형 · 타원 · 삼각형 · 오각형 · 화살표(→ ⇒) · 선 · 화살표 선 · 말풍선. 도형 안에 텍스트 입력 가능. 채우기 색 · 윤곽선 색/두께/대시 |
| 그림 | 비율 유지 크기 조절, 원래 크기로 다시 설정. (자르기·그림 효과는 이후) |
| 표 | 행/열 추가·삭제, 셀 텍스트, 테두리 기본 스타일 |
| 비디오 | YouTube 링크 → 편집 화면은 썸네일, 쇼에서는 재생 |
| 아이콘 | 앱 선 아이콘을 벡터 개체로 삽입, 색 변경 |

### 개체 조작 (PowerPoint 와 동일한 동작)
- 클릭 선택, **Shift/Ctrl+클릭** 다중 선택, 빈 곳에서 드래그로 영역 선택
- 8개 크기 조절 핸들 + 회전 핸들. **Shift** 비율 유지/15° 단위 회전, **Ctrl** 가운데 기준 크기 조절
- **Ctrl+드래그** 복제, **Shift+드래그** 수평/수직으로만 이동
- 스마트 가이드: 슬라이드 가운데·가장자리, 다른 개체 가장자리·가운데에 맞추면 빨간 점선 + 달라붙음 (**Alt** 누르면 끄기)
- 방향키 이동, **Ctrl+방향키** 미세 이동
- 텍스트 개체: 한 번 클릭 = 개체 선택(테두리 실선), 다시 클릭/더블클릭 = 텍스트 편집(테두리 점선)
- 그룹 / 그룹 해제, 맞춤(왼쪽·가운데·오른쪽·위쪽·중간·아래쪽, 가로/세로 간격 동일하게)
- 선택 창: 개체 목록, 이름, 보이기/숨기기, 순서 변경

### 슬라이드 쇼 중 (PowerPoint 와 동일)
| 키 | 동작 |
|---|---|
| `→` `↓` `Space` `Enter` `N` `PageDown` | 다음 |
| `←` `↑` `Backspace` `P` `PageUp` | 이전 |
| 숫자 + `Enter` | 해당 번호 슬라이드로 |
| `Home` / `End` | 처음 / 마지막 |
| `B` / `W` | 검은 화면 / 흰 화면 |
| `Ctrl+L` | 레이저 포인터 |

## 8. 파일: 불러오기 · 저장 · 다운로드 · PDF 출력

PowerPoint 의 **파일 탭(백스테이지)** 과 같은 구성으로 한 곳에 모은다.

```
파일 ─┬ 새로 만들기      빈 프레젠테이션 / 템플릿에서
      ├ 열기             프레젠테이션 목록 · 최근 항목
      ├ 불러오기         .pptx · 이미지 · PDF · 노트 페이지
      ├ 저장             Ctrl+S (자동 저장 켜짐 표시)
      ├ 복사본 저장      다른 이름으로 저장
      ├ 버전 기록        저장 시점 목록 · 미리보기 · 복원
      ├ 다운로드         .pptx · PDF · 이미지(.png) · MarkNote 백업
      ├ 인쇄 / PDF       인쇄 설정 화면
      └ 정보             슬라이드 수 · 만든 날짜 · 파일 크기
```

### 8-1. 불러오기

| 가져올 것 | 결과 | 비고 |
|---|---|---|
| **.pptx** (주 대상) | 새 프레젠테이션 또는 현재 프레젠테이션 뒤에 슬라이드 추가 | `python-pptx` 로 읽음. 텍스트(글꼴·크기·색·굵게 등 서식), 도형(종류·채우기·윤곽선), 그림, 표, 노트, 숨긴 슬라이드, 위치·크기·회전을 개체 단위로 변환 |
| 이미지 여러 장 | 이미지 1장 = 슬라이드 1장 (가운데 맞춤) | 사진 앨범처럼 |
| PDF | 페이지 1장 = 슬라이드 1장 (그림으로) | 편집은 불가, 발표·주석용. `pypdfium2` (라즈베리파이 ARM 지원) |
| MarkNote 노트 페이지 | `#` 제목·목록·이미지를 "제목 및 내용" 슬라이드로 | `---` 또는 제목 기준으로 나눔 |
| MarkNote 백업 (.mnslides) | 그대로 복원 | 아래 다운로드의 무손실 형식 |

- 불러오기 전 **미리보기 화면**: 슬라이드 수, 변환되지 않는 요소 목록(예: SmartArt 3개 → 그림으로 대체 / 애니메이션 무시), 새로 만들기 vs 현재 뒤에 추가 선택
- 지원하지 않는 개체는 버리지 않고 **가능하면 그림으로 대체**(pptx 안의 미리보기 이미지 사용), 불가하면 "변환 안 됨" 자리표시 개체로 남김
- 끌어다 놓기: 목록 화면에 .pptx 를 놓으면 바로 불러오기
- 제한: 파일 100MB, 슬라이드 500장, 압축 해제 합계 제한 (노트 가져오기와 같은 안전장치)

### 8-2. 저장

| 항목 | 동작 |
|---|---|
| **자동 저장** | 변경 후 0.8초 멈추면 해당 슬라이드 저장. 제목 줄에 `저장 중… / 저장됨 / 오프라인 — 저장 대기` 표시 (PowerPoint 웹과 같음) |
| **Ctrl+S** | 대기 중인 변경을 즉시 저장 + **버전 기록에 저장 시점 추가** |
| 저장 실패 대비 | 서버에 못 보낸 변경은 브라우저에 임시 보관 → 다시 연결되면 자동 전송, 창 닫기 전 경고 |
| **복사본 저장** | 다른 이름으로 저장 (전체 복제, 원본 유지) |
| **버전 기록** | Ctrl+S 시점 + 자동 스냅샷(편집 중 10분마다, 최대 50개) 목록 → 미리보기 → "이 버전으로 복원"(현재 상태도 버전으로 남긴 뒤 복원) |
| 실행 취소 | 프레젠테이션 단위 명령 기록 (슬라이드 추가/삭제/이동, 개체 변경) — 세션 동안 유지 |

### 8-3. 다운로드

| 형식 | 내용 | 용도 |
|---|---|---|
| **.pptx** | 위치·크기·회전·텍스트 서식·도형·그림·표·노트·숨김 상태를 그대로 → **PowerPoint·Keynote·구글 슬라이드에서 편집 가능** | 다른 사람에게 전달 |
| **PDF** | 아래 8-4 인쇄 설정과 같은 옵션 | 배포·보관 |
| **이미지** | 슬라이드별 PNG (zip) 또는 현재 슬라이드만 | 메신저·문서 첨부 |
| **MarkNote 백업 (.mnslides)** | 슬라이드 JSON + 이미지를 묶은 zip, **무손실** | 백업·다른 MarkNote 로 옮기기 |

- 노트의 `📦 전체 내보내기` 백업에 프레젠테이션도 포함 (`presentations/` 폴더에 .mnslides)
- 파일 이름 기본값: 프레젠테이션 제목 (금지 문자 제거)

### 8-4. 인쇄 · PDF 출력 (PowerPoint 인쇄 화면 기준)

```
┌ 인쇄 설정 ─────────────────┐┌ 미리보기 ────────────────────┐
│ 범위   ● 모든 슬라이드        ││  ┌──────────┐                │
│        ○ 현재 슬라이드        ││  │ 슬라이드 1 │   ◀ 1 / 12 ▶  │
│        ○ 사용자 지정 [1-3,5]  ││  └──────────┘                │
│ 레이아웃 ▾ 전체 페이지 슬라이드 ││                              │
│          노트 페이지           ││                              │
│          유인물 1·2·3·4·6·9    ││                              │
│ □ 숨긴 슬라이드 인쇄          ││                              │
│ □ 슬라이드 테두리             ││                              │
│ 색 ▾ 컬러 / 회색조 / 흑백      ││                              │
│ 머리글·바닥글 (날짜, 쪽 번호)  ││                              │
│ 용지  ▾ 슬라이드 크기 / A4 가로 ││                              │
│ [ PDF로 저장 ]  [ 인쇄 ]      ││                              │
└───────────────────────────┘└──────────────────────────────┘
```

| 레이아웃 | 쪽 구성 |
|---|---|
| 전체 페이지 슬라이드 | 1쪽 = 슬라이드 1장 |
| 노트 페이지 | 위 슬라이드 + 아래 노트 (A4 세로) |
| 유인물 | 1·2·3·4·6·9 슬라이드/쪽, 3장일 때는 옆에 필기 줄 |

**만드는 방식 (2가지 중 선택)**
| 방식 | 장점 | 단점 |
|---|---|---|
| ① 인쇄용 화면 + 브라우저 "PDF로 저장" (기본) | 화면과 **완전히 같은 모양**, 추가 프로그램 없음 | 브라우저 인쇄 창을 한 번 거침 |
| ② 서버에서 PDF 파일 바로 생성 (선택) | 버튼 한 번에 .pdf 파일 다운로드 | 서버에 헤드리스 Chromium 필요 (라즈베리파이 `chromium` 패키지로 가능, 메모리 사용 큼) |

→ 1차는 ①, 필요하면 ② 를 설정에서 켜도록.

### 8-5. 좌표·글꼴 기준

좌표계: 슬라이드 **1280 × 720** 논리 단위 = PowerPoint 16:9 기본 크기(33.867 × 19.05 cm). `.pptx` 변환 시 1단위 = 9525 EMU.
4:3 (960 × 720) 도 슬라이드 크기 설정으로 지원 (PowerPoint "슬라이드 크기").
기본 글꼴: **맑은 고딕** (한국어 Office 기본), 크기 단위는 pt (PowerPoint 의 크기 목록 8 ~ 96).
.pptx 에 쓰인 글꼴이 없으면 비슷한 글꼴로 대체하고 불러오기 결과에 표시.

## 12. AI 에이전트 — 편집하고 꾸미기

노트에 붙인 AI 도우미(서버의 Claude Code + MarkNote MCP 도구)를 프레젠테이션에도 연결한다.

**결정 (2026-10-27): 슬라이드는 AI 가 바로 수정한다.** 처음 기획은 노트처럼 "변경안 → [적용]" 이었지만,
조언·제안만 하는 AI 는 쓸모가 없다는 판단으로 바꿨다. 대신 안전장치는:
- 한 번의 `edit_deck` 호출은 **전부 적용되거나 전혀 적용되지 않음** (작업 하나라도 틀리면 아무것도 바뀌지 않고 AI 에게 오류를 돌려줌)
- 적용 전 슬라이드 전체를 `AiDeckEdit` 에 보관 → 채팅 카드의 **[되돌리기]** 로 원래대로
- AI 수정 뒤에 사용자가 또 고쳤으면 되돌리기 전에 "그 뒤의 변경도 사라집니다" 확인 → [그래도 되돌리기]
- 설정 화면의 **"프레젠테이션 바로 수정"** 을 끄면 AI 는 슬라이드를 바꾸지 못하고 글로만 제안 (기본 켜짐)
- 노트는 지금처럼 승인 후 적용 (노트는 긴 글이라 diff 를 보고 고르는 편이 낫다)

### 12-1. 할 수 있는 일 (예시 요청)

| 분류 | 예시 요청 | AI 가 하는 일 |
|---|---|---|
| **만들기** | "MarkNote 소개 10장짜리 발표자료 만들어줘", "이 노트 페이지로 발표자료 만들어줘" | 레이아웃 고르고 슬라이드·개체 생성, 노트 작성 |
| **편집** | "3번 슬라이드 글 줄여줘", "전체 오타 고쳐줘", "슬라이드 순서 자연스럽게 바꿔줘", "5번을 두 장으로 나눠줘" | 텍스트 수정, 슬라이드 추가/삭제/이동/분할 |
| **꾸미기** | "전체를 깔끔한 다크 톤으로", "제목 글꼴·크기 통일", "이 슬라이드 개체들 정렬해줘", "표지 더 눈에 띄게" | 색·글꼴·크기·배경·정렬·간격 조정, (4단계 이후) 테마·전환·애니메이션 적용 |
| **점검 (발표 코치)** | "발표 전 점검해줘" | 글이 넘치는 슬라이드, 너무 작은 글자, 화면 밖 개체, 대비가 낮은 색, 노트 없는 슬라이드 목록 + 고치는 변경안 |
| **노트 작성** | "슬라이드마다 발표자 노트 써줘", "10분 발표 분량으로" | 노트 칸 채우기, 예상 발표 시간 |

### 12-2. 화면

- 편집기 오른쪽에 **AI 도우미 서랍** (노트와 같은 패널) — **`F2`** 또는 화면 오른쪽 끝의 "AI 도우미" 손잡이를 누르면 오른쪽에서 밀려 나옴 *(구현됨)*
- **구현된 흐름**: "2번 슬라이드 제목 줄여줘" → AI 가 `read_deck` 으로 ID 확인 → `edit_deck` 으로 적용 → 편집기가 서버의 최신 상태로 **바로 다시 그려짐** → 채팅에 "슬라이드 수정함 · 발표 이름 / 요약 (작업 N개) / ✓ 적용됨 [되돌리기]" 카드
  - 다른 프레젠테이션을 고쳤으면 카드에 [열기]
  - PowerPoint 의 `F2`(텍스트 편집)는 AI 도우미에 양보하고, 텍스트 편집은 `Enter`·더블클릭으로
- 참고 범위 칩: `현재 슬라이드` · `선택한 개체` · `전체 프레젠테이션` — 기본은 현재 슬라이드
- 개체·슬라이드 우클릭 → "AI 로 다듬기", "AI 로 꾸미기"
- *(아래는 처음 기획 — 바로 적용으로 바꾸면서 보류)* **변경안 카드**: 바뀌는 슬라이드마다 **전/후 축소판을 나란히** + 바뀐 점 요약("제목 크기 28→40pt, 배경 #fff→#1f1f1f")
  - 슬라이드별 [적용] / [거절], 카드 전체 [모두 적용]
  - 적용하면 편집 창이 바로 갱신되고, **실행 취소(Ctrl+Z) 한 번으로 되돌릴 수 있음** (적용 전 상태는 버전 기록에도 남김)
  - 사용자가 그사이 같은 슬라이드를 고쳤으면 충돌 경고 → "그래도 적용"

### 12-3. AI 가 쓰는 도구 (MarkNote MCP 서버에 추가)

| 도구 | 동작 | 상태 |
|---|---|---|
| `list_decks` | 프레젠테이션 목록 (휴지통 제외) | 구현 |
| `read_deck` | 슬라이드 전체 JSON: 슬라이드 ID·번호·레이아웃·노트·배경 + 개체(ID·이름·종류·개체 틀 역할·위치·크기·텍스트·서식), 레이아웃·글꼴 목록 | 구현 |
| `edit_deck` | 작업 목록을 **바로 적용** (전부 또는 전혀), 요약 한 줄과 함께 기록 → 되돌리기 가능 | 구현 |
| `render_slide` | 슬라이드를 **이미지로** 받아 보기 — 꾸밈 판단용 (서버 PNG 렌더링 필요, 토큰도 큼) | 보류 |
| `create_deck` | 새 프레젠테이션 만들기 | 보류 |

질문할 때마다 지금 보는 프레젠테이션의 글·위치 요약은 stdin(`<presentation>`)으로 따로 들어가므로, 간단한 수정은 `read_deck` 없이도 할 수 있다.

**작업(operation) 목록 형식** — 편집기 자동 저장과 **같은 형식** (`app/services/deck_ops.py`). AI 가 쓰기 쉽도록 `deck_tools.py` 가 몇 가지를 대신 풀어 준다:
```json
[
  {"op": "update_element", "slide": 2, "element": "제목 1", "set": {"text": "<b>요약</b>", "style": {"fontSize": 40}}},
  {"op": "add_slide", "after": 3, "layout": "title_content", "texts": {"title": "정리", "body": "<div>하나</div><div>둘</div>"}},
  {"op": "add_element", "slide": 1, "element": {"type": "shape", "shape": "round_rect", "x": 80, "y": 600, "w": 300, "h": 60, "text": "NEW"}},
  {"op": "update_slide", "slide": 4, "set": {"background": "#1f1f1f", "notes": "발표자 노트"}},
  {"op": "move_slide", "slide": 5, "to": 0},
  {"op": "delete_element", "slide": "s1a2b3c4d5e", "element": "e9f8e7d6c5"}
]
```
- 슬라이드는 ID 또는 **번호(1부터, 이번 수정 전 기준)**, 개체는 ID 또는 **이름**("제목 1")으로 가리킬 수 있음
- 새 개체 ID 는 서버가 만듦, `add_slide` 의 `texts` 로 레이아웃 개체 틀(title·subtitle·body·body2·header·header2·caption)에 바로 글 채우기
- 서버가 적용 전에 **검증**: 존재하는 슬라이드·개체인지, 값이 허용 범위(글꼴 목록, 크기, 좌표, 색 형식)인지, 텍스트 HTML 정화. 그림은 AI 가 추가할 수 없음
- AI 가 지원하지 않는 꾸미기(예: 아직 없는 애니메이션)를 요청받으면 "현재 지원하지 않음"을 답하고 가능한 대안 제안

### 12-4. 설계 원칙 (1단계부터 지킬 것)

- **모든 편집을 작업(operation) 단위로 처리** — 사용자 편집·실행 취소·버전 기록·AI 제안이 같은 작업 목록을 쓰면, AI 기능을 붙일 때 편집기를 다시 만들 필요가 없다
- 개체·슬라이드에 **안정적인 ID** (AI 가 "e7 개체"처럼 정확히 가리킬 수 있게)
- 개체에 **이름**(선택 창의 이름: "제목 1", "그림 3") — AI 와 사용자가 같은 이름으로 말할 수 있게
- 권한·설정: 설정 화면에 **"프레젠테이션 바로 수정"** 항목 (구현됨, 기본 켜짐), 초기 프롬프트는 노트와 공통 적용
- AI 는 프레젠테이션·노트 외의 PC 파일이나 명령 실행에는 접근 불가 (노트 AI 와 동일)

## 13. 정해야 할 것

1. 사이드바 `노트 | 프레젠테이션` 탭 방식으로 진행할지
2. 1단계 완료 기준: "만들고 → 텍스트·도형·그림 배치 → 저장 → F5 로 발표" 까지면 충분한지
3. PDF 출력: 기본 ①(브라우저 PDF 저장)으로 시작하고, 버튼 한 번 다운로드(②, 서버 Chromium)는 나중에 켤지
4. 11장 추천 기능 중 넣을 것
5. AI 의 `render_slide`(슬라이드를 이미지로 보고 꾸미기)는 서버에서 PNG 를 만들어야 함 — PDF ② 와 같은 서버 Chromium 을 쓰면 한 번에 해결. 둘을 같이 켤지
